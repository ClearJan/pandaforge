# Third-Party Components & Licenses

RobotStudio bundles and builds on the following open-source components.
All runtime-required assets live inside this repository so the project runs
offline. This file records what is third-party, where it came from, and under
which license it is redistributed.

## Robot model: Franka Emika Panda (bundled)

- Source: https://github.com/google-deepmind/mujoco_menagerie
  (`franka_emika_panda/` directory)
- Pinned revision: commit `f3b6013629c7b94f8ee93fd977b161fa8350f9bc`
  (2026-10-23)
- Vendored SUBSET in `assets/robots/panda/`: `panda.xml`,
  `panda_nohand.xml`, the collision/visual meshes under `assets/`, the
  upstream `LICENSE` (Apache-2.0), `README.md` and `CHANGELOG.md` — all
  byte-identical to upstream. The unused upstream variants (MJX models,
  standalone `hand.xml`, demo `scene.xml`, preview image) were omitted.
- The `rs_scene_*.xml` files next to the model are GENERATED by the scene
  builder (`src/robotstudio/simulation/scenes.py`) and include `panda.xml`
  unmodified; they are committed so the project runs offline out of the box.
- Description: official MuJoCo MJCF model with collision meshes, hand and
  gripper actuators (actuator8 = tendon-coupled gripper, ctrl 0..255).

## Algorithms

RRT, RRT-Connect, Damped Least Squares IK, time-scaled cubic spline
parameterization and the grasp state machine are INDEPENDENTLY implemented in
this repository (`src/robotstudio/`), written from the original publications
(see docs/ALGORITHMS.md for references). No third-party robotics code was
copied.
